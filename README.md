# Радар вакансий → твой телеграм-бот

Каждые полчаса обходит 28 телеграм-каналов с вакансиями, отбирает то, что
подходит именно тебе — веб-дизайн, вёрстка, разовые заказы на лендинги
и обычная удалёнка вроде менеджера или ассистента, — проверяет каждую
вакансию на развод и присылает в личку с вердиктом и временем публикации.

Перепечатки с бирж (Kwork, FL.ru и прочие «перейти к заявке») отсекаются:
откликаться там всё равно надо за деньги, толку от них нет.

Работает на GitHub бесплатно и круглосуточно. Твой компьютер при этом
может быть выключен.

---

## Что приходит в бот

```
✅ НОРМ · Веб-дизайн
💰 80 000 – 120 000 ₽

Вакансия: Веб-дизайнер (удалённо)
Компания «Айти-Студия» ищет веб-дизайнера в команду.

Обязанности:
— дизайн лендингов и многостраничников в Figma
…

👍 описаны обязанности, перечислены требования, названа форма оформления

🔗 Открыть  ·  @design_vacancy
```

А развод приходит так — или не приходит вовсе, смотря как настроишь:

```
⚠️ СОМНИТЕЛЬНАЯ · Проектная работа
💰 зП не указана

Нужны 7 желающих для работы с искусственным интеллектом.
Требования: 18-45 лет. Доход от 5000 руб в день…

⚠️ Что настораживает:
• указан возрастной диапазон — в нормальных вакансиях так не пишут
• набирают «N желающих» — так ищут не дизайнера, а массовку
• обещают заработок «в день» — типичная приманка

🔗 Открыть  ·  @frilans
```

## Установка

### Шаг 1. Запустить на своём компьютере

Два двойных клика, терминал открывать не нужно.

**1. Кликни `NASTROIT.bat`**

Мастер проведёт по шагам: попросит токен бота, сам найдёт твой `chat_id`
и проверит связь. Токен берётся так — открой телеграм, найди
**@BotFather**, отправь `/newbot`, придумай имя и логин (логин обязан
кончаться на `bot`). В ответ придёт длинная строка вида
`1234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw` — её и вставляешь.

По ходу мастер попросит найти своего бота в телеграме и нажать
**«Запустить»**. Это обязательно: пока ты сам не напишешь боту,
телеграм не разрешает ему писать тебе первым.

**2. Кликни `ZAPUSTIT.bat`**

Вакансии придут в бота. Это ручной запуск — работает, пока компьютер
включён. Чтобы радар работал сам и круглосуточно, делай шаги 2 и 3.

> Если предпочитаешь терминал — все команды в конце файла.

### Шаг 2. Выложить на GitHub

Здесь радар и будет жить: сервер GitHub сам запускает его каждые полчаса,
твой компьютер при этом может быть выключен. Это бесплатно.

Никаких команд — всё мышкой через сайт.

**1.** Заведи аккаунт на [github.com](https://github.com), если его нет.

**2.** Нажми **+** в правом верхнем углу → **New repository**.
Имя — `job-radar`. Тип оставь **Public** (публичный).

> Почему публичный: у бесплатных приватных репозиториев лимит 2000 минут
> в месяц, а при запуске раз в полчаса мы упрёмся в него впритык.
> У публичных лимита нет. Токен всё равно никто не увидит — он хранится
> отдельно, в Secrets, и в коде его нет.

**3.** На странице пустого репозитория нажми **uploading an existing file**.

Открой папку `job-radar` в проводнике и перетащи в браузер файлы:

```
config.py     analyzer.py    sources.py     notifier.py
storage.py    main.py        setup.py       requirements.txt
README.md     .gitignore     .env.example
папку .github
```

> ⚠️ **Файл `.env` не перетаскивай.** В нём лежит твой токен, а репозиторий
> публичный. При загрузке через сайт защита `.gitignore` не работает —
> что перетащил, то и опубликовалось. Токен попадёт на GitHub вместе
> с файлом, и бота смогут угнать. Загружай всё остальное, `.env` нужен
> только у тебя на компьютере.

Внизу нажми **Commit changes**.

**4.** Проверь, что папка `.github` загрузилась — она должна быть в списке
файлов. Если её нет (браузеры иногда пропускают папки с точкой в начале),
создай файл вручную: **Add file** → **Create new file**, в поле имени
впиши

```
.github/workflows/radar.yml
```

и вставь туда содержимое такого же файла с компьютера. Нажми
**Commit changes**.

### Шаг 3. Включить автозапуск

Осталось передать серверу токен — тот же, что вводил в мастере настройки.
Оба значения лежат у тебя в файле `.env`, открой его блокнотом и копируй
оттуда.

**1.** В своём репозитории: **Settings** (шестерёнка сверху) → в левом меню
**Secrets and variables** → **Actions**.

**2.** Кнопка **New repository secret**. Добавь два секрета по очереди —
имя вписывай буква в букву:

| Name | Secret |
|---|---|
| `TG_BOT_TOKEN` | строка после `TG_BOT_TOKEN=` из файла `.env` |
| `TG_CHAT_ID` | число после `TG_CHAT_ID=` из файла `.env` |

Секреты видит только сервер при запуске. Даже ты сам потом не сможешь
их прочитать — только заменить.

**3.** Вкладка **Actions** вверху. Если GitHub спросит разрешение на
запуск — согласись (**I understand my workflows, go ahead and enable them**).

**4.** Слева выбери **Радар вакансий** → справа кнопка **Run workflow** →
ещё раз **Run workflow**. Это ручная проверка.

Через минуту-две в бота придут вакансии. Дальше радар просыпается сам
каждые полчаса — можешь выключать компьютер.

**Как проверить, что он живой:** зайди на вкладку **Actions**. Там список
запусков. Зелёная галочка — отработал, красный крестик — упал, кликни
по нему и увидишь причину.

> Радар после каждого запуска сам сохраняет в репозиторий файл `seen.json` —
> это его память о том, что уже присылал. Поэтому в списке коммитов будут
> появляться записи «память радара» от `job-radar`. Так и должно быть.

## Как настроить под себя

Всё живёт в файле `config.py`, остальное трогать не нужно.

**Добавить канал** — впиши его логин в список `CHANNELS`:

```python
CHANNELS = [
    "design_vacancy",
    "мой_новый_канал",   # ← вот так
]
```

Работают только **публичные** каналы. Проверить просто: открой
`t.me/s/имя_канала` в браузере. Видно посты — подойдёт. Закрытые каналы
и чаты (например `@Uyut_frilans`) так читать нельзя.

**Поднять или опустить планку по деньгам:**

```python
MIN_SALARY = 60_000          # зарплата за месяц по профилю
MIN_SALARY_OTHER = 35_000    # зарплата на обычной удалёнке
MIN_PROJECT_BUDGET = 5_000   # бюджет разового заказа
```

Пороги специально разные: 15 000 ₽ за лендинг — нормальная цена проекта,
а 15 000 ₽ в месяц зарплатой быть не может. Обычная удалёнка почти всегда
дешевле дизайнерской, и общий порог срезал бы её подчистую.

**Выключить обычную удалёнку** — если менеджеры и операторы не нужны
и хочется только веб:

```python
SEND_OTHER_REMOTE = False
```

**Не хочешь видеть сомнительные:**

```python
SEND_SUSPICIOUS = False
```

**Слишком много или слишком мало приходит** — крути `RELEVANCE_MIN`.
Больше 3 — строже отбор и меньше сообщений, меньше 3 — наоборот.

## Как он решает, что вакансия — развод

Не по одному слову, а по совокупности. Один настораживающий признак
ничего не значит, а три вместе — почти всегда развод.

Что считается тревожным звоночком:

- возрастные рамки «18-45 лет» — в легальной вакансии их не пишут
- «нужны 7 желающих» — так набирают массовку, а не дизайнера
- «доход от 5000 в день», «пассивный доход», «заработок в интернете»
- просят деньги вперёд: взнос, депозит, платное обучение
- крипта, ставки, казино
- «все подробности в личку» вместо описания задачи
- текст в три строки без единой конкретики

Что, наоборот, говорит в пользу вакансии: описаны обязанности и
требования, названа компания, указана форма оформления, есть ссылка
на hh.ru, просят портфолио.

Итог — один из трёх вердиктов:

| | Что значит |
|---|---|
| ✅ **НОРМ** | признаков развода нет, вакансия выглядит живой |
| ⚠️ **СОМНИТЕЛЬНАЯ** | приходит с пометкой и списком причин — решай сам |
| ⛔ **НЕ НОРМ** | явный развод, по умолчанию не присылается вовсе |

## Подключить hh.ru

Работает и без этого — по умолчанию источник выключен, и вакансии идут
только из телеграма.

hh закрыл свободный доступ к своему API: раньше можно было просто
запрашивать вакансии, теперь на любой запрос без токена приходит отказ.
Токен получают так:

1. Зайти на [dev.hh.ru](https://dev.hh.ru) под своим обычным аккаунтом hh
2. Личный кабинет → **Создать приложение**
3. Дождаться письма с подтверждением
4. На [dev.hh.ru/admin](https://dev.hh.ru/admin) скопировать `access_token`
5. Добавить его третьим секретом на GitHub под именем `HH_TOKEN`

Заявку могут и отклонить — это решение hh, повлиять на него нельзя.
Телеграм от этого не пострадает, он работает отдельно.

## Если что-то пошло не так

**В бот ничего не приходит.** Проверь, что ты нажал «Запустить» в диалоге
с ботом. Без этого телеграм запрещает боту писать первым.

**«Нет TG_BOT_TOKEN или TG_CHAT_ID».** Локально — проверь файл `.env`,
на GitHub — секреты в Settings → Secrets and variables → Actions.
Имена должны совпадать буква в букву.

**Приходит слишком много.** Подними `MIN_SALARY`, увеличь `RELEVANCE_MIN`
до 4-6, поставь `SEND_SUSPICIOUS = False`, убери лишние каналы.

**Приходит слишком мало.** Опусти `RELEVANCE_MIN` до 2, добавь каналов,
проверь `STOP_WORDS` — возможно, что-то нужное отсекается стоп-словом.

**Хочу получить всё заново.** `python main.py --reset` очистит память,
и следующий запуск пришлёт всё, что найдёт.

**Посмотреть, что нашлось, ничего не отправляя** — `python main.py --dry`.

## Из чего состоит

| Файл | Зачем |
|---|---|
| `config.py` | все настройки — единственный файл, который правишь ты |
| `sources.py` | забирает посты из телеграм-каналов и с hh.ru |
| `analyzer.py` | решает, твоя ли это вакансия и не развод ли |
| `notifier.py` | собирает сообщение и шлёт в бот |
| `storage.py` | помнит отправленное, чтобы не слать дважды |
| `main.py` | связывает всё вместе |
| `setup.py` | мастер настройки, запускается из `NASTROIT.bat` |
| `seen.json` | память; создаётся сам при первом запуске |
